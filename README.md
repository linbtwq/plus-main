# Movie Tracker & Roulette (plus.plus)

Веб-приложение для ведения личной библиотеки фильмов, аниме и сериалов с глубокой системой оценки и интерактивными механиками выбора. Проект ориентирован на визуальное удобство и азартный подход к выбору контента. Выполнен в праздничном ретро-стиле 70-х.

## Основной функционал

### 1. Продвинутая система рейтинга
* **Многофакторная оценка:** Каждый тайтл оценивается по 100-балльной шкале с помощью набора слайдеров.
* **Статус «Шедевр»:** При достижении оценки 10.0 карточка фильма получает золотое оформление, покачивающуюся корону и свечение.
* **Категоризация:** Четкое разделение контента на Фильмы, Сериалы и Аниме.

### 2. Интерактивная рулетка (Slot Machine)
* **Механика игрового автомата:** Выбор того, что посмотреть, реализован в виде слот-машины с Motion Blur и плавным торможением.
* **Настройка времени:** Пользователь может выставить время вращения барабана (от 1 до 10 секунд).
* **Режим «Выбывание»:** Выпавший фильм автоматически удаляется из списка планов.

### 3. Техническая реализация
* **Синхронизация данных:** Firebase для хранения личных оценок и списка рулетки.
* **Интерфейс и UX:** Ретро-дизайн с элементами кинопленки, новогодними гирляндами, кастомными 3D-эффектами наклона карточек (Tilt) и падающим золотым снегом (Canvas).
* **Адаптивность:** Полная поддержка мобильных браузеров.

## Локальный запуск

Это статический сайт с JavaScript-модулями. Откройте его через HTTP, например:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/index.html`. Для Google-входа домен должен быть разрешён в Firebase Authentication.

## База данных и публикация

Архив личный: чтение, создание и удаление доступны владельцу записи. Новые записи сохраняют TMDB ID, исходный тип тайтла и версию схемы. Старые оценки при просмотре не изменяются; недостающий TMDB ID определяется поиском при открытии плеера или трейлера.

Записи архива загружаются по 48 штук. Фильтры, поиск и статистика относятся к уже загруженным записям; следующая порция открывается кнопкой «Загрузить ещё».

Список рулетки синхронизируется в документе `roulette/{uid}`. Локальная копия изолирована по аккаунтам. Старый общий список браузера можно явно добавить кнопкой на странице рулетки; исходная копия не удаляется.

Правила `firestore.rules` и индекс `firestore.indexes.json` необходимо опубликовать вместе с обновлённым сайтом. `firestore.rules.txt` оставлен как идентичная копия для ручного переноса в консоль Firebase. Из среды с установленным Firebase CLI и доступом к проекту:

```sh
firebase deploy --only firestore:rules,firestore:indexes --project films-28c85
```

Дождитесь готовности составного индекса `movies: userId ASC, timestamp DESC`. Пока новые правила не опубликованы, облачная синхронизация рулетки недоступна, а прежние разрешения базы остаются действующими.

## Проверки

Требуются Node.js 22.13+ и Chromium-совместимый браузер. Установите зависимости и укажите путь к исполняемому файлу браузера:

```sh
npm install
npx playwright-core install chromium --only-shell
BROWSER_PATH=/path/to/chromium npm test
```

Тесты проверяют опасные HTML-значения, изоляцию аккаунтов, старые записи, пагинацию архива и поиска, запоздавшие ответы, переходы между страницами и центрирование рулетки при смене размеров экрана. В браузерных тестах Firebase и TMDB заменены локальными ответами; реальная база не изменяется. Они не заменяют проверку опубликованных правил в Firebase Emulator и проверку доступности внешних плееров.
